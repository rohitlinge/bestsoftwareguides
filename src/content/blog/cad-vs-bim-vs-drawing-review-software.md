**Short answer:** **CAD** software draws lines and shapes in 2D or 3D. **BIM** software builds a model out of building objects (walls, doors, windows) so plans, sections and schedules all come from one source. **Drawing review software** does not create designs: it opens the PDF drawing sets exported from CAD or BIM so teams can mark them up, measure quantities, compare revisions and track issues. Architects usually need CAD or BIM; contractors, estimators, consultants and owners usually need drawing review software; many firms use both.

## What does BIM add over CAD?

In CAD, a wall is two lines; change the wall and you redraw it on every plan, section and elevation. In BIM, a wall is an object with a type, height and materials. Change it once and every view, schedule and quantity updates. That is why BIM tools cost more and take longer to learn, and why most architecture firms that produce full construction documents use them.

Some tools sit in between. AutoCAD's Architecture toolset adds wall, door and window objects to DWG drafting. SketchUp and Rhino are 3D modellers used for concept and form-finding rather than full documentation; Rhino needs plug-ins for BIM objects.

## Where does drawing review software fit?

Once a design is issued, it usually travels as a PDF drawing set. The people who build, price or approve the project rarely work in the architect's CAD or BIM file. They need to:

- **Mark up** comments and clouds on the sheets.
- **Measure** lengths, areas and counts for quantity takeoff.
- **Compare revisions** to see what changed between issues.
- **Track issues** such as RFIs and punch list items pinned to the drawing.

That is what drawing review software does, and it works the same whichever CAD or BIM tool produced the PDFs. Planspector (a [featured partner](/disclosure/) of this site), Fieldwire, Drawboard Projects and STACK run in a web browser; Bluebeam Revu and PlanSwift are Windows desktop apps.

## Do you need both?

Often, yes. Architects design in CAD or BIM and then review consultants' drawings, run design checks and answer contractor questions on the PDF sets. Contractors never need the BIM tool but live in drawing review software. The two are complementary, not alternatives: a drawing review tool cannot create a design, and a CAD or BIM tool is a heavy, expensive way to mark up a PDF.
